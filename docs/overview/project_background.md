# Project Background

## 背景

社内には大量のPDFドキュメント（仕様書・マニュアル・規程類）が存在するが、目的の情報を検索・参照するには時間がかかり、業務効率の低下を招いていた。

また、社員が情報を探す際に外部のAIサービスを利用するケースが増加しており、機密情報の漏洩リスクが懸念されていた。

## 課題

| 課題 | 内容 |
|------|------|
| 情報検索の非効率 | 大量のPDFから目的の情報を探すのに時間がかかる |
| 情報漏洩リスク | 外部AIサービスへの機密情報の入力リスク |
| 知識の属人化 | 特定の担当者にしか情報が集まっていない |
| ドキュメントの陳腐化 | 更新されたドキュメントへのアクセスが困難 |

## 目的

- 社内PDFドキュメントを活用したRAG（Retrieval-Augmented Generation）システムを構築する
- 社内ネットワーク内でのみ動作するセキュアなAIチャットシステムを提供する
- 社員が自然言語で質問し、関連ドキュメントに基づいた回答を得られる環境を整備する

## 期待効果

| 効果 | 内容 |
|------|------|
| 業務効率化 | 情報検索時間の削減 |
| セキュリティ向上 | 社内完結による情報漏洩リスクの低減 |
| 知識の民主化 | 誰でも社内ドキュメントにアクセス可能 |
| コスト削減 | 外部AIサービスの利用費削減 |

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | ai_chat |
