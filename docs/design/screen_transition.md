# Screen Transition
<div align="right">作成日: 2026-06-05</div>

## 画面遷移図

```mermaid
flowchart TD
    Login[ログイン画面]
    Chat[チャット画面]
    Doc[ドキュメント管理画面]
    Settings[設定画面]

    Login -->|認証成功| Chat
    Login -->|認証失敗| Login
    Chat -->|メニュー選択\n管理者権限| Doc
    Chat -->|設定アイコン| Settings
    Doc -->|戻るボタン| Chat
    Settings -->|戻るボタン| Chat
```

---

## 画面遷移一覧

| 遷移元 | 遷移先 | トリガー | 条件 |
|--------|--------|---------|------|
| ログイン画面 | チャット画面 | ログインボタン | 認証成功 |
| ログイン画面 | ログイン画面 | ログインボタン | 認証失敗（エラー表示） |
| チャット画面 | ドキュメント管理画面 | メニュー選択 | 管理者権限 |
| チャット画面 | 設定画面 | 設定アイコン | なし |
| ドキュメント管理画面 | チャット画面 | 戻るボタン | なし |
| 設定画面 | チャット画面 | 戻るボタン | なし |

---

## 各画面の初期表示

| 画面 | 初期表示内容 |
|------|------------|
| ログイン画面 | ログインフォーム |
| チャット画面 | 「こんにちは！何でも聞いてください。」 |
| ドキュメント管理画面 | 登録済みドキュメント一覧 |
| 設定画面 | 現在のユーザー設定 |
