# Screen Transition
<div align="right">作成日: 2026-06-05　最終更新日: 2026-06-08</div>

## 画面遷移図

```mermaid
flowchart TD
    Login[ログイン画面]
    Chat[チャット画面]
    Indexer[PDFインデクサー画面\n/api/indexer]
    Settings[設定画面]
    Docs[ドキュメントビューア\n/api/specs]

    Login -->|認証成功| Chat
    Login -->|認証失敗| Login
    Chat -->|メニュー選択\n管理者権限| Indexer
    Chat -->|設定アイコン| Settings
    Chat -->|ドキュメントアイコン| Docs
    Indexer -->|戻るボタン| Chat
    Settings -->|戻るボタン| Chat
    Docs -->|戻るボタン| Chat
```

---

## 画面遷移一覧

| 遷移元 | 遷移先 | トリガー | 条件 |
|--------|--------|---------|------|
| ログイン画面 | チャット画面 | ログインボタン | 認証成功 |
| ログイン画面 | ログイン画面 | ログインボタン | 認証失敗（エラー表示） |
| チャット画面 | PDFインデクサー画面 | メニュー選択 | 管理者権限 |
| チャット画面 | 設定画面 | 設定アイコン | なし |
| チャット画面 | ドキュメントビューア | ドキュメントアイコン | なし |
| PDFインデクサー画面 | チャット画面 | 戻るボタン | なし |
| 設定画面 | チャット画面 | 戻るボタン | なし |
| ドキュメントビューア | チャット画面 | 戻るボタン | なし |

---

## 各画面の初期表示

| 画面 | 初期表示内容 |
|------|------------|
| ログイン画面 | ログインフォーム |
| チャット画面 | 「こんにちは！何でも聞いてください。」 |
| PDFインデクサー画面 | data/配下のPDFファイル一覧 |
| 設定画面 | 現在のユーザー設定 |
| ドキュメントビューア | 目次（README.md） |
