### SCR-001: チャット画面

```
┌─────────────────────────────────────┐
│  ai_chat                    [設定]  │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────────────────────┐   │
│  │ AI: こんにちは！何でも聞い  │   │
│  │ てください。                │   │
│  └─────────────────────────────┘   │
│                                     │
│         ┌──────────────────────┐   │
│         │ ユーザー: 〇〇につい │   │
│         │ て教えてください     │   │
│         └──────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ AI: 〇〇については...       │   │
│  │ [参照: document.pdf p.3]    │   │
│  └─────────────────────────────┘   │
│                                     │
├─────────────────────────────────────┤
│  [質問を入力...]          [送信]   │
└─────────────────────────────────────┘
```

**UI要素:**

| 要素 | 仕様 |
|------|------|
| チャット履歴 | スクロール可能・最新メッセージを下部に表示 |
| 入力フォーム | 複数行入力対応・Enterで送信 |
| 送信ボタン | 入力中はローディング表示 |
| 参照ドキュメント | クリックでドキュメント名・ページ数を表示 |
