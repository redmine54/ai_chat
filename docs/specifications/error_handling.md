# Error Handling

## エラーハンドリング仕様

### HTTPエラーコード

| コード | 意味 | 対応 |
|--------|------|------|
| 400 | Bad Request | リクエストパラメータの検証エラー |
| 401 | Unauthorized | 認証エラー |
| 403 | Forbidden | 権限エラー |
| 404 | Not Found | リソースが存在しない |
| 422 | Unprocessable Entity | バリデーションエラー |
| 500 | Internal Server Error | サーバー内部エラー |
| 503 | Service Unavailable | サービス利用不可 |

---

### アプリケーションエラーコード

| エラーコード | 内容 | 対応 |
|------------|------|------|
| E001 | ChromaDB接続エラー | リトライ後にエラーレスポンスを返す |
| E002 | LLM APIエラー | エラーメッセージをユーザーに返す |
| E003 | PDFパースエラー | スキップしてログに記録 |
| E004 | ベクトル化エラー | エラーメッセージをユーザーに返す |
| E005 | ドキュメント未検索 | 「関連ドキュメントが見つかりません」を返す |

---

### エラーレスポンス形式

```json
{
  "error": {
    "code": "E001",
    "message": "ChromaDBへの接続に失敗しました",
    "detail": "Connection refused at vectordb-service:8000"
  }
}
```

---

### リトライポリシー

| 対象 | リトライ回数 | 待機時間 |
|------|------------|---------|
| ChromaDB接続 | 3回 | 1秒、2秒、4秒（指数バックオフ） |
| LLM API | 2回 | 2秒、4秒 |

---

### ログレベル

| レベル | 用途 |
|--------|------|
| DEBUG | 開発時の詳細ログ |
| INFO | 正常系の処理ログ |
| WARNING | 軽微なエラー・リトライ |
| ERROR | 処理失敗・要対応 |
| CRITICAL | システム停止レベルのエラー |

---

### ユーザー向けエラーメッセージ

| 状況 | メッセージ |
|------|----------|
| 回答生成失敗 | 「申し訳ありません。回答の生成に失敗しました。しばらく経ってから再試行してください。」 |
| 関連ドキュメントなし | 「ご質問に関連するドキュメントが見つかりませんでした。別の言葉で質問してみてください。」 |
| システムエラー | 「システムエラーが発生しました。管理者にお問い合わせください。」 |
