# Functional Requirements

## 機能要件

### FR-001: チャット機能

| ID | 要件 |
|----|------|
| FR-001-1 | ユーザーはテキストで質問を入力できる |
| FR-001-2 | システムは質問に対する回答を返却する |
| FR-001-3 | 回答には参照したドキュメント名を表示する |
| FR-001-4 | チャット履歴を表示できる |

### FR-002: ドキュメント管理機能

| ID | 要件 |
|----|------|
| FR-002-1 | 管理者はPDFドキュメントをアップロードできる |
| FR-002-2 | アップロードされたPDFは自動的にベクトル化される |
| FR-002-3 | ドキュメントの削除・更新が可能である |

### FR-003: RAG機能

| ID | 要件 |
|----|------|
| FR-003-1 | 質問に関連するドキュメントをベクトル検索で取得する |
| FR-003-2 | 取得したドキュメントをコンテキストとしてLLMに送信する |
| FR-003-3 | LLMが生成した回答をユーザーに返却する |

### FR-004: セキュリティ機能

| ID | 要件 |
|----|------|
| FR-004-1 | サービス間通信はmTLSで暗号化する |
| FR-004-2 | 外部通信はHTTPSで暗号化する |
| FR-004-3 | 認証済みユーザーのみアクセス可能とする |

### FR-005: API機能

| ID | 要件 |
|----|------|
| FR-005-1 | RESTful APIを提供する |
| FR-005-2 | APIドキュメント（Swagger UI）を提供する |
| FR-005-3 | ヘルスチェックエンドポイントを提供する |
