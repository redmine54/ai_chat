# Functional Requirements
<div align="right">作成日: 2026-06-05　最終更新日: 2026-06-08</div>

## 機能要件

### FR-001: チャット機能

| ID | 要件 |
|----|------|
| FR-001-1 | ユーザーはテキストで質問を入力できる |
| FR-001-2 | システムは質問に対する回答を返却する |
| FR-001-3 | 回答には参照したドキュメント名を表示する |
| FR-001-4 | チャット履歴を表示できる |

### FR-002: PDFインデックス化機能

| ID | 要件 |
|----|------|
| FR-002-1 | 管理者はWebUI（/api/indexer）からPDFファイル一覧を確認できる |
| FR-002-2 | 管理者はWebUIから対象PDFを選択してインデックス化を実行できる |
| FR-002-3 | インデックス化の結果（チャンク数・ステータス）をWebUIで確認できる |
| FR-002-4 | インデックス化対象PDFは `src/backend/data/` 配下に配置する |
| FR-002-5 | インデックス化はAPI（POST /api/pdf/index）経由でも実行できる |

### FR-003: RAG機能

| ID | 要件 |
|----|------|
| FR-003-1 | 質問に関連するドキュメントをGemini text-embedding-004でベクトル検索する（TOP_K=5） |
| FR-003-2 | 取得したドキュメントをコンテキストとしてLLMに送信する |
| FR-003-3 | LLMが生成した回答をユーザーに返却する |
| FR-003-4 | LLMはGoogle Gemini API（gemini-1.5-flash）を使用する |
| FR-003-5 | PDFの埋め込みモデルはGemini text-embedding-004を使用する |

### FR-004: セキュリティ機能

| ID | 要件 |
|----|------|
| FR-004-1 | サービス間通信はmTLS（STRICT）で暗号化する |
| FR-004-2 | 外部通信はHTTPSで暗号化する（Istio Gateway） |
| FR-004-3 | 認証済みユーザーのみアクセス可能とする |
| FR-004-4 | GEMINI_API_KEYは環境変数で管理しソースコードへの直接記載を禁止する |

### FR-005: API機能

| ID | 要件 |
|----|------|
| FR-005-1 | RESTful APIを提供する（POST /api/chat） |
| FR-005-2 | APIドキュメント（Swagger UI）を提供する（/swagger/docs） |
| FR-005-3 | ヘルスチェックエンドポイントを提供する（GET /health） |
| FR-005-4 | PDFファイル一覧APIを提供する（GET /api/pdf/list） |
| FR-005-5 | PDFインデックス化APIを提供する（POST /api/pdf/index） |

### FR-006: ドキュメントビューア機能

| ID | 要件 |
|----|------|
| FR-006-1 | プロジェクトドキュメントをWeb表示できる（/api/specs） |
| FR-006-2 | 左サイドバーでカテゴリ・ファイルを選択できる |
| FR-006-3 | Markdownをレンダリングして表示する |
| FR-006-4 | Mermaid記法の図を表示できる |
