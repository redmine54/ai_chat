# Use Cases

## ユースケース一覧

### UC-001: 質問する

| 項目 | 内容 |
|------|------|
| アクター | 社内従業員 |
| 概要 | ユーザーが自然言語で質問し、AIが回答を返す |
| 事前条件 | ユーザーが認証済みであること |
| 事後条件 | 回答がチャット画面に表示される |

**基本フロー:**
1. ユーザーがチャット画面を開く
2. ユーザーが質問を入力する
3. システムが質問をベクトル化する
4. システムがChromaDBから関連ドキュメントを検索する
5. システムがLLMに質問と関連ドキュメントを送信する
6. LLMが回答を生成する
7. システムが回答をユーザーに返却する

---

### UC-002: ドキュメントをアップロードする

| 項目 | 内容 |
|------|------|
| アクター | システム管理者 |
| 概要 | 管理者がPDFドキュメントをシステムに登録する |
| 事前条件 | 管理者権限でログインしていること |
| 事後条件 | PDFがベクトル化されてChromaDBに保存される |

**基本フロー:**
1. 管理者がドキュメント管理画面を開く
2. 管理者がPDFファイルを選択する
3. システムがPDFをテキスト抽出する
4. システムがテキストをチャンク分割する
5. システムが各チャンクをベクトル化する
6. システムがChromaDBにベクトルを保存する

### UC-004: システムの稼働状態を確認する

| 項目 | 内容 |
|------|------|
| アクター | システム管理者 |
| 概要 | 管理者がシステムの稼働状態を確認する |
| 事前条件 | なし |
| 事後条件 | 各コンポーネントの状態が表示される |

**基本フロー:**
1. 管理者がヘルスチェックエンドポイントにアクセスする
2. システムが各コンポーネントの状態を返却する
