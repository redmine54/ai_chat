# Non-functional Requirements
<div align="right">作成日: 2026-06-05</div>

## 非機能要件

### NFR-001: パフォーマンス

| ID | 要件 | 目標値 |
|----|------|--------|
| NFR-001-1 | チャット応答時間 | 30秒以内 |
| NFR-001-2 | ドキュメント検索時間 | 3秒以内 |
| NFR-001-3 | 同時接続ユーザー数 | 10ユーザー以上 |

### NFR-002: 可用性

| ID | 要件 | 目標値 |
|----|------|--------|
| NFR-002-1 | 稼働時間 | 営業時間内（平日9:00-18:00） |
| NFR-002-2 | 計画外停止 | 月1回以内 |

### NFR-003: セキュリティ

| ID | 要件 |
|----|------|
| NFR-003-1 | サービス間通信はmTLS（STRICT）で暗号化 |
| NFR-003-2 | 外部通信はTLS 1.2以上で暗号化 |
| NFR-003-3 | 社内ネットワーク外からのアクセス禁止 |
| NFR-003-4 | 認証・認可の実装 |

### NFR-004: 保守性

| ID | 要件 |
|----|------|
| NFR-004-1 | GitOpsによる構成管理 |
| NFR-004-2 | CI/CDによる自動テスト・デプロイ |
| NFR-004-3 | ログの集中管理 |
| NFR-004-4 | ドキュメントの整備（/specsで参照可能） |

### NFR-005: スケーラビリティ

| ID | 要件 |
|----|------|
| NFR-005-1 | Kubernetesによるスケールアウト対応 |
| NFR-005-2 | ドキュメント数の増加に対応可能 |

### NFR-006: コスト

| ID | 要件 | 目標値 |
|----|------|--------|
| NFR-006-1 | インフラコスト（Minikube） | $0（ローカル） |
| NFR-006-2 | インフラコスト（AKS） | $50/月以内 |

### NFR-007: 移植性

| ID | 要件 |
|----|------|
| NFR-007-1 | docker compose・Minikube・AKSの3環境で動作可能 |
| NFR-007-2 | Mac M1/M2/M3（ARM64）での動作保証 |
